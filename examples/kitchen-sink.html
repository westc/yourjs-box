Module blocks (data-block-type="module")

Each block runs like a <script type="module">, so top-level await and import work but declarations stay in their block.

Babel removes the types (without checking them) before each block runs. Errors point to the TypeScript code.

Web Worker (the default)

Code runs in a Web Worker so it can't touch the page. Reset stops code that never finishes.

Window mode (data-runner="window")

Code runs directly in this page so it can use the page's globals and DOM.
