YourJSBox API

This page loads the script in its <head> and creates consoles with YourJSBox.create(). Pick a placement to see where the console goes relative to the dashed target.

The console’s height defaults to 100% of its container. For replace, before and after its container is this page, which has no set height, so the console is its minimum height (150px) unless you give it a height (eg. 400px).
