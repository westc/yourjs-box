A JavaScript console you can drop into any page

Add one script tag and your readers get an interactive console with step-by-step code blocks and output that looks just like the browser’s dev tools.

Try it now Get started See examples
<script src="https://cdn.jsdelivr.net/npm/yourjs-box@1/dist/yourjs-box.min.js"></script>

Press Run (or Ctrl/⌘+Enter) to step through the code. Hover over code that already ran to copy it back into the editor.

Or let the code control your page

By default code runs in a Web Worker, safely away from your page. Add data-runner="window" and it runs in the page itself, so it can use your page’s DOM and functions.

Everything you need to teach or demo JavaScript

No build step, no framework and nothing to configure.

One script tag

Put your code inside the script tag and the console appears right where the tag is.

Step-by-step blocks

Comments ending in \\ split your code into blocks that run one at a time.

Dev tools-style output

Expandable objects, Maps, Sets, classes, console.table() and familiar errors.

Sandboxed by default

Code runs in a Web Worker away from your page. Reset even stops infinite loops.

Or run in your page

Use data-runner="window" to give code access to your page’s globals and DOM.

Hidden setup code

Hide helper code that still runs, with a click to reveal it for the curious.

Light & dark themes

Follows the visitor’s system theme, or pick one with data-theme.

Style-proof

The console lives in an iframe so your CSS and its CSS never collide.

Get started

Add the script wherever you want the console to appear. The console fills its container, so give the container a height. 

<div style="height: 400px">
  <script src="https://cdn.jsdelivr.net/npm/yourjs-box@1/dist/yourjs-box.min.js">
    // Say hello \\
    console.log('Hello world!');

    // Show a table \\
    console.table([{name: 'Ada', born: 1815}, {name: 'Grace', born: 1906}]);
  </script>
</div>
AttributeDescription
data-block-type "classic" (default) runs each block like a regular script so variables carry over. "module" runs each block as a module so top-level await and import work.
data-show-results "false" hides the value of the last expression in each block.
data-libraries-url Where to load Vue, Ace, Prism and Acorn from (eg. /node_modules/{name}/ to host them yourself). Loaded from unpkg by default.
data-runner "worker" (default) runs code in a Web Worker. "window" runs it in the page.
data-divider-orient "vertical" puts the editor beside the output and "horizontal" puts it below. By default it’s beside the output unless the console is narrower than 600px.
data-hide-prefix Blocks whose header starts with this prefix are hidden but still run (eg. // SETUP: Helpers \\).
data-theme "light" or "dark". Follows the system’s theme by default.
